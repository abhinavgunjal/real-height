# CelebHeight — Celebrity Real Height Truth Database & Visual Comparison Studio

An interactive web application that reveals the real physical heights of **Bollywood & Hollywood** celebrities, exposing the discrepancies between **IMDb / Agency Claimed Heights** and **Verified Barefoot Stature** (sourced from forensic photo analysis, co-star calibrations, and athletic combine records).

## 🌟 Key Features

1. **Dual-Source Stature Verification**:
   - **Claimed Height**: Official agency listings, studio press kits, and IMDb bio records.
   - **Real Verified Height**: Barefoot measurements, photographic evidence, and Rob Paul's CelebHeights analysis.
   - **Exaggeration Index**: Automated calculation of padding/inflation (e.g., Tom Cruise +1.9", Dwayne 'The Rock' Johnson +2.5", Sylvester Stallone +2.0").
   - **Shoe Lifts & Footwear Evidence**: Documented analysis of custom elevator shoes, Cuban heels, and platform wedges.

2. **Visual Scale Comparison Studio**:
   - Accurately proportioned side-by-side scale visualization on a calibrated barefoot measuring wall.
   - Laser head-level guidelines with dynamic difference indicators (e.g., *"The Rock is 7.5 inches taller than Tom Cruise"*).
   - **"Compare With You"**: Custom height slider and avatar allowing users to stand directly beside Hollywood stars.
   - Quick preset matchups: *Action Trio*, *Spider-Man Couple*, *Short vs. Tall Extremes*.

3. **Live IMDb & Wikidata API Engine**:
   - Real-time search engine querying **IMDb Suggestion API** and **Wikidata Knowledge Graph (P2048)**.
   - Look up virtually *any* celebrity on Earth on-demand with high-resolution photos and official citations.

4. **Hollywood Truth Meter & Leaderboards**:
   - *The Wall of Inflation*: Hollywood's biggest height inflators.
   - *The 100% Honest Club*: Celebrities who never embellished their agency listings (e.g., Daniel Radcliffe, Zendaya, Brad Pitt, Conan O'Brien).
   - *Short Kings & Queens* (≤ 5'7" / 170 cm).
   - *Towering Titans* (≥ 6'3" / 190 cm).

5. **Universal Unit Converter**:
   - Instant 1-click toggle between **Imperial (`ft / in`)** and **Metric (`cm`)** across all cards, charts, and studios.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation & Run

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Or run the optimized production server (currently running on port 3000)
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## 📁 Project Architecture

- `src/types/celebrity.ts`: TypeScript schemas for celebrities, height metrics, and custom comparison users.
- `src/lib/heightUtils.ts`: Precise conversion algorithms between metric centimeters, feet, inches, fractions, and exaggeration levels.
- `src/data/celebrities.ts`: Curated database of 40+ top-searched stars with photographic notes, quotes, and sources.
- `src/app/api/search-celebrity/route.ts`: Server-side API endpoint combining IMDb Suggest API + Wikipedia summary + Wikidata P2048 claim.
- `src/components/Navbar.tsx`: Header navigation, unit switcher, and studio quick drawer.
- `src/components/CelebrityCard.tsx`: Stature card with real vs. claimed height metrics and lift badges.
- `src/components/HeightComparisonStudio.tsx`: Proportional physical height simulator with ruler gridlines.
- `src/components/CelebrityDetailModal.tsx`: In-depth breakdown with quotes, lift notes, and external links.
- `src/components/TruthMeterLeaderboard.tsx`: Four-quadrant leaderboard ranking Hollywood's most honest vs. inflated stars.
